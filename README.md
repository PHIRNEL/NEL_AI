# NEL_AI sur Vercel
1. Poussez ce dossier sur GitHub.
2. Sur vercel.com : Add New > Project > importez le dépôt (Framework : Vite, détecté automatiquement).
3. Settings > Environment Variables : `API_FOOTBALL_KEY` (clé api-football.com). Optionnel : sans clé, la saisie manuelle fonctionne.
4. Deploy. Ou en ligne de commande : `npm i -g vercel && vercel --prod`.
Test local : `vercel dev`.
